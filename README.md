# WebLuxe High Fashion Boutique: Starter demo

The first tier of the WebLuxe clothing-shop demos: one tidy page in ivory and rani pink.
Live: https://webluxe.github.io/LowTier_ClothingBoutique/

All pieces, prices, photos, names and addresses are examples. In demo mode the WhatsApp and call buttons show a popup instead of contacting anyone.

## What it has
- Hero, category cards, the whole collection with category buttons and a WhatsApp button on every piece
- Tap a photo to see it bigger
- How to order, both boutiques with opening hours
- `/admin`: owner panel (demo mode keeps changes in the visitor's browser)

## Files
| File | What it does |
|---|---|
| `index.html` | The page |
| `assets/app.js`, `assets/style.css` | The collection grid and the styles |
| `data.js` | Pieces (written by the owner panel) |

For a real client: set `whatsapp` in `SHOP` at the top of `assets/app.js` and remove the `demo/` scripts.
